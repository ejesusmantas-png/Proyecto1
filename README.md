## Project Overview
**MicroMove** is a mobile solution designed to address sedentary behavior in university libraries. The core challenge tackled is the "social inhibition" students feel when they want to stretch or move in quiet, shared spaces. MicroMove provides discreet, low-impact exercise suggestions that can be performed at a desk without drawing attention.

## Refinements & Final Improvements
Based on the User Testing phase, the following enhancements were implemented:
1. **Visual Accessibility:** Increased contrast and touch-target size for the main "Start" action.
2. **Navigation Clarity:** Added descriptive text labels to exercise icons.
3. **Environmental Adaptation:** Optimized haptic feedback (vibration patterns) for quiet environments.

## System Architecture
* **Frontend:** Mobile Application (Figma High-Fidelity Prototype).
* **Logic Layer:** Real-time sedentary monitoring using smartphone sensors.
* **Data Layer:** Cloud integration for user history and energy statistics.
